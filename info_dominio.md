# Informações do Domínio - Pasta Ecom

**Domínio Principal:** `optimalife.online`

**Objetivo:** Este domínio foi configurado para ser utilizado em campanhas de Google Ads (fundo de funil/pre-sell), especificamente voltado para produtos físicos e ofertas de e-commerce gerais.

Ele transmite uma ideia relacionada à "vida ideal/otimizada" e será utilizado para todos os projetos salvos nesta pasta (`Ecom`).

### Estrutura de URL Recomendada
Para criar páginas para diferentes produtos usando o mesmo domínio, utilize subdiretórios com o nome do produto:

* `https://www.optimalife.online/ProdutoA`
* `https://www.optimalife.online/ProdutoB`

Exemplo de uso com parâmetros de rastreamento do Google Ads:
`https://www.optimalife.online/NomeDoProduto?utm_id={campaignid}&utm_source=google&utm_medium={adgroupid}&utm_campaign=nomeCampanha&utm_term={keyword}&utm_content={creative}&network={network}&device={device}&ftgid=ftgid_{gclid}_ftgid`

### Hospedagem e Repositório
* **Repositório GitHub:** [https://github.com/Uildigital/ecom.git](https://github.com/Uildigital/ecom.git)
* **Hospedagem:** Vercel

Isso significa que as atualizações feitas nos projetos desta pasta devem ser enviadas (via Git) para o repositório `ecom.git` para refletirem automaticamente no domínio ao vivo através da Vercel.
